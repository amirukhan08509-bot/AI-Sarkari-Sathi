# 🇮🇳 AI Sarkari Sathi

### Government Schemes Made Easier with AI

**AI Sarkari Sathi** is a Flutter-based Android application designed to help users discover and understand Indian Central and State Government schemes in a simple and accessible way.

The application combines government scheme discovery, profile-based assistance, Firebase services and an AI assistant in one mobile experience.

---

## 🚀 Key Features

- 🔎 Search government schemes
- 🏛️ Browse schemes by State and Category
- 🤖 AI-powered scheme assistance
- 👤 User Login & Profile
- ☁️ Firebase Authentication
- 🔥 Cloud Firestore profile storage
- 📄 Document assistance
- 📍 Government office information
- 🌐 Official scheme website access
- 📞 Scheme helpline information
- 🎯 Eligibility and required document information
- 🔐 Secure server-side AI integration

---

## 🤖 AI Assistant

The built-in AI assistant helps users understand government schemes in simple Hindi.

Users can ask questions related to:

- Scheme eligibility
- Benefits
- Required documents
- Application process
- Suitable schemes based on their situation

AI API credentials are not stored inside the Android application. AI requests are handled through a secure backend layer.

## 🔒 Security

The application follows a server-side API architecture.

Sensitive AI API credentials are stored on the backend and are not bundled inside the APK.

Firebase security rules are used to protect user profile data.

---

## 📱 Platform

Currently available as an **Android application**.

The project is built using Flutter, allowing future expansion to additional supported platforms.

---

## 🎯 Project Purpose

AI Sarkari Sathi was created to demonstrate how modern mobile development and AI can make public information easier to discover and understand.

This is an independent informational project and is **not an official Government of India or State Government application**.

Users should verify important scheme information through the relevant official government portal before applying.
